      **Security fix (2026-08-11, post-hoc via background security review, not caught before shipping):** `journey_server.py`'s state-changing POST endpoints (`/api/delete`, `/api/content`) had no CSRF/DNS-rebinding defense — reasoned through a real working exploit (a hidden cross-origin `text/plain` `<form>` auto-submit from any webpage the user has open while the server runs would bypass CORS preflight entirely and could silently delete real memory/knowledge/candidate files).
